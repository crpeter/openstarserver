# Periodic-box lane ownership

This folder owns `openstar.box-period-search.v1`. Preserve the established
`boxPeriodSearch.frequencyWindows` dataset contract, worker payload, full
structural validation, candidate ordering, status fields, and ledger metric
names. This workload is distinct from the historical TESS period-search alias.

Lane tests belong in the matching periodic-box test folder. Shared platform or
coordinator changes require a separate foundation task.
